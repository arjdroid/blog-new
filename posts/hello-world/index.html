This blog is written in Typst and compiled to static HTML in a single pass. No JavaScript build pipeline, no Markdown, no front matter — just .typ files and one typst compile.

1.Why Typst¶

Typst 0.15 exports genuinely semantic HTML: headings become <h2>, lists become <ul>, and equations become MathML rather than images. That means the output is selectable, searchable, and readable by screen readers.

The same source that produces this page could produce a PDF, which is the part that made the whole idea worth trying.
