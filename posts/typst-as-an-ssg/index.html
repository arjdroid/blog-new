Deploying my blog with typst

September 2, 2026 #typst #web

Typst 0.15 added bundle export: a single project can emit many output files. A page is a document, a raw file is an asset, and one compile writes the entire site.

1.The shape of it¶

Everything the site emits lives in one entry file:

#document("index.html", title: "Home")[...]
#asset("style.css", read("/assets/style.css", encoding: none))

Because the templates build <html>, <head> and <body> by hand, Typst skips its own skeleton and the stylesheet link lands where it belongs.

2.Styling¶

Typst emits no CSS of its own — deliberately. The markup is semantic and the styling is an ordinary hand-written stylesheet, which is a better division of labour than it first sounds: the content layer never has to know about pixels.

One exception: Typst injects a small stylesheet for MathML alignment, so equations like

∑ 𝑘 = 1 𝑛 𝑘 = 𝑛 ( 𝑛 + 1 ) 2

render correctly without any help from us.

3.The one rough edge¶

Typst cannot list a directory, so posts have to be enumerated by hand in content/posts.typ. Two lines per post, and in exchange there is no build script anywhere in the project.
